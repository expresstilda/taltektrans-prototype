# Прототип сайта ТалТЭК Транс (ТТТ)

Кликабельный HTML-прототип имиджевого сайта-визитки. Цель — согласовать **структуру и тексты**, после утверждения передать дизайнеру (далее вёрстка на Битрикс, домен `.pro`).

## Как открыть
- Двойной клик по `index.html` — откроется в браузере. Все страницы связаны навигацией.
- Либо локальный сервер: `python -m http.server 5599 --directory prototype` → http://localhost:5599

## Страницы
1. **index.html** — Главная: hero (видео/фото), что мы делаем, перевозки по номенклатуре, цифры (тизер), география, CTA.
2. **about.html** — О компании: кто мы, цифры и факты, парк вагонов 2026, сильные стороны, схема направлений, миссия.
3. **services.html** — Услуги и подвижной состав: 2 услуги, процесс «под ключ» (6 шагов), модели вагонов 6 (+1), гарантии.
4. **contacts.html** — Контакты: форма «Обращение/запрос», коммерческий департамент, диспетчеры (Москва/Питер), 6 офисов.

Сквозные элементы: кнопка «Личный кабинет» с пометкой «в разработке», переключатель RU/EN (заглушка).

## Принятые решения (по брифу и созвону 06.05.2026)
- **Тексты от лица клиента**, без избытка «мы/наши» — по замечанию Антона (Client First). Девиз «Мы не ждём лучших времён…» вынесен в строку над заголовком.
- **Hero адаптивный**: видео на десктопе, фото-постер на мобайле/медленном интернете (референс up.com, taltek.net).
- **Форма вместо 3 почт**: одна форма с выбором типа вагона (полувагон / крытый / хоппер-зерновоз) + один общий адрес `zayavka@taltektrans.pro`. Адреса pv@/kv@/zv@ не показываем. Слово «запрос», не «заявка».
- **Цифры статичные**, без бегущих счётчиков (предпочтение Марии). Анимация — опционально.
- **Хопперы-зерновозы** — выделены как новое направление 2026 (+1 модель).

## Плейсхолдеры (что заменит дизайнер/клиент)
- Видео hero, карта направлений, карта офисов.
- Фото в карточках: в подписях указаны рекомендованные кадры из папки `Фото ТТТ АВ/PHOTO` (напр. DSC08533, DSC08604, DSC08492 — составы с логотипом, золотой час).
- Фото сотрудников комдепа.

## Открытые вопросы к клиенту
1. Характеристики и фото остальных моделей вагонов (заявлено 6 (+1), данные есть по 12-2159 и 11-2163).
2. Телефоны и часы работы диспетчеров (Москва / Санкт-Петербург).
3. Финальный адрес для запросов (`zayavka@…` — предложение).
4. Состав коммерческого департамента для сайта + фото.
5. Реквизиты юрлица для подвала.
6. Нужен ли блок «Миссия/Ценности» на главной или достаточно на «О компании».

## Заметки по бренду (для дизайнера)
- Цвета: глубокий синий, основной синий, светло-серый, белый; золотой/оранжевый акцент — зерновое направление.
- Логотип в прототипе — упрощённая SVG-заглушка; использовать оригинальный знак из брендбука.
- Фирменный шрифт — из брендбука Талтэк (в прототипе системный).
